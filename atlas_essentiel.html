Atlas E.

Atlas Essentiel

Un atlas interactif entièrement hors ligne : tout ce que tu vois est embarqué dans ce fichier. Aucune connexion, aucun compte, aucune collecte — jamais.

Le contrat

Chaque thème est dérivé de banques vérifiables incluses dans l'application : la liste officielle du patrimoine mondial UNESCO (1 245 sites, avec leur année d'inscription), les capitales et grandes villes recensées, les volcans du catalogue Smithsonian, les centrales nucléaires civiles, les sommets majeurs et le palmarès FIFA. Rien n'est estimé, rien n'est inventé ; une valeur absente reste absente.

Voyager dans le temps

Les thèmes marqués ◷ se déroulent année par année : le curseur (ou ▶) rejoue l'histoire — les inscriptions UNESCO depuis 1978, le nucléaire depuis 1956, les Coupes du monde depuis 1930.

Limites assumées

La carte utilise des frontières généralisées (échelle 1:110 M) : les micro-États n'y figurent pas. Les banques sont des sélections documentées, pas des inventaires exhaustifs du monde.
